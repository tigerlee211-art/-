# 네이버 블로그 자동화

관심 키워드나 주제를 넣으면 AI가 글감을 찾고, 글을 쓰고, 사진을 구하거나 만든 뒤, 네이버 블로그에
직접 타이핑해서 발행까지 해주는 프로그램입니다. 컴퓨터에 설치해서 쓰는 개인용 프로그램이고,
모든 자료는 내 컴퓨터의 `data` 폴더 안에만 저장됩니다(외부 서버에 올라가지 않습니다).

아래 순서대로 하나씩 따라 하시면 됩니다. 한 번에 다 안 하셔도 됩니다 — 시작 준비만 끝나면
그다음은 프로그램 화면 안에서 진행됩니다.

---

## 1. 시작하기 전에 — 준비물 확인 (한 번만 하면 됩니다)

**명령어를 입력하는 창**을 열어주세요.
- 맥: `Command + 스페이스` 를 누르고 "터미널" 이라고 입력한 뒤 엔터
- 윈도우: 시작 메뉴에서 "터미널" 또는 "명령 프롬프트" 검색

그 창에 아래 줄을 그대로 붙여넣고 엔터를 눌러주세요.

```bash
node --version && claude --version
```

- 숫자가 두 줄 나오면 준비가 다 된 것입니다. 3번으로 넘어가세요.
- `command not found` 같은 게 나오면 아래에서 하나씩 설치하세요.

### Node.js가 없다고 나올 때

1. https://nodejs.org 에 들어가서 왼쪽의 "LTS" 라고 쓰인 버튼을 눌러 내려받으세요.
2. 내려받은 설치 파일을 열어서 계속 다음을 눌러 설치하세요.
3. 설치가 끝나면 터미널 창을 닫았다가 다시 열고, 위의 확인 명령어를 다시 입력해 숫자가 나오는지 봐주세요.

### `claude`가 없다고 나올 때

이 프로그램은 여러분이 이미 구독 중인 Claude 요금제로 AI를 사용합니다(추가 요금이 붙지 않습니다).
그러려면 컴퓨터에 `claude` 라는 프로그램이 설치돼 있어야 합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

설치가 끝나면 아래를 입력해 로그인하세요(안내에 따라 브라우저가 열립니다).

```bash
claude login
```

로그인까지 끝났으면 맨 위의 확인 명령어를 다시 입력해 숫자 두 줄이 나오는지 확인해 주세요.

---

## 2. 필요한 프로그램 내려받기

이 폴더(프로젝트 폴더) 안에서 명령어 창을 열고 아래를 입력하세요.

```bash
npm install
```

몇 분 정도 걸릴 수 있습니다. 끝나면 다음 줄이 보일 때까지 기다렸다가 다음으로 넘어가세요.

---

## 3. 앱 켜기

```bash
npm run dev
```

잠시 뒤 주소가 나오면 브라우저에서 **http://localhost:4123** 을 열어주세요.
어두운 화면에 위쪽이 초록색인 화면이 뜨면 성공입니다.

> ⚠️ 이 명령어 창은 **켜둔 채로** 두세요. 이 창을 닫으면 앱도 꺼집니다.
> 앱을 끄고 싶을 때는 이 창에서 `Ctrl + C` 를 누르면 됩니다.

---

## 4. 네이버에 로그인하기

**네이버에 대신 글을 올리려면 로그인을 한 번 해두어야 합니다.**

화면 위쪽의 **[네이버 로그인]** 버튼을 눌러주세요. 새 창이 뜨면 평소처럼 로그인하시면 됩니다.

**"로그인 상태 유지"에 꼭 체크해 주세요.** 체크하지 않으면 몇 시간 뒤 다시 로그인해야 하고,
글을 읽는 건 되는데 정작 글쓰기만 안 되는 헷갈리는 상황이 생길 수 있습니다.

로그인이 끝나면 창이 저절로 닫히고, 화면의 "네이버" 표시에 초록불이 켜집니다.

> 처음 로그인을 시도하면 브라우저 프로그램을 자동으로 받는 과정이 한 번 있을 수 있습니다.
> 몇 분 정도 걸릴 수 있으니 창이 바로 안 뜨더라도 잠시 기다려 주세요.

---

## 5. (선택) AI가 사진을 직접 그리게 하기

**안 하셔도 앱은 다 돌아갑니다.** 사진을 검색해서 가져오거나, 직접 찍은 사진을 써도 됩니다.
다만 검색으로 가져온 사진은 저작권 문제가 있을 수 있어서, AI가 직접 그리는 쪽이 더 안전합니다.

하시려면:

1. 이 폴더에 있는 `env.sample` 파일을 복사해서 `.env.local` 이라는 이름으로 만드세요.
   - 맥: `cp env.sample .env.local`
   - 윈도우: `copy env.sample .env.local`
2. 메모장 같은 프로그램으로 `.env.local` 파일을 열어서, Cloudflare 계정의 Account ID와
   API 토큰 값을 빈칸에 채워 넣고 저장하세요.
3. **채운 뒤에는 3번의 앱을 껐다가(`Ctrl+C`) 다시 켜주세요(`npm run dev`).** 안 하면 값이 반영되지 않습니다.

무료로 하루 8~40장 정도 만들 수 있습니다(그림체·품질에 따라 다르며, 설정 화면에서 확인할 수 있습니다).

---

## 6. 첫 글 만들어보기 — 연습 모드

이 프로그램은 안전을 위해 **처음엔 항상 "연습 모드"** 로 시작합니다. 연습 모드에서는
**실제로 블로그에 올라가지 않고**, 완성되면 어떤 모습인지 화면 캡처만 보여줍니다.

1. 화면에서 원하는 글 유형(자동 발굴 / 체험단 / 브랜딩·전문성)을 골라주세요.
2. 관심 있는 키워드나 주제를 한두 단어로 넣어주세요. (예: 제주도 여행, 홈카페)
3. 사진을 어떻게 구할지 골라주세요.
4. **[연습으로 만들기]** 를 눌러주세요.

3~7분 정도 걸립니다. 중간에 브라우저 창이 저절로 열렸다 닫히는데 **건드리지 마세요.**
다 되면 완성된 글과 사진이 화면에 보입니다.

---

## 7. 실제로 올리기 — 신중하게 결정하는 단계 ⚠️

연습으로 만든 글이 마음에 드시면, 이제 진짜로 올릴 수 있습니다.

**여기서부터는 되돌릴 수 없습니다.** 글이 실제 블로그에 올라갑니다.

처음에는 **비공개**로 올려보시길 권합니다(설정에 이미 비공개로 되어 있습니다). 나만 볼 수 있어서
어떻게 나오는지 먼저 확인하고, 마음에 들면 나중에 블로그에서 공개로 바꿀 수 있습니다.

준비되셨으면 오른쪽 위 **[설정]** 을 열어 **연습 모드**를 꺼주세요. 그다음 다시
**[글 만들고 발행하기]** 를 누르면 실제로 올라갑니다.

발행이 끝나면 화면에 실제 글 주소가 뜹니다. 열어서 글과 사진이 제대로 들어갔는지 확인해 주세요.
테스트 삼아 올린 글이라면 블로그에서 글 오른쪽 위 **[삭제]** 로 지우셔도 됩니다.

---

## 안전장치 — 왜 이렇게 조심스러운가

자동으로 글을 올리는 것은 네이버 이용약관상 계정 제재 위험이 있습니다. 그래서 이 프로그램은
기본적으로 매우 보수적으로 동작합니다.

- **연습 모드**가 기본으로 켜져 있습니다 — 발행하지 않고 화면만 보여줍니다.
- **하루에 올릴 수 있는 글 수**와 **발행 사이 최소 간격**이 정해져 있습니다(설정에서 조절 가능).
- **전체 중단** 스위치를 켜면 어떤 상황에서도 발행되지 않습니다.
- 공개 범위 기본값은 **비공개**입니다.
- 검색으로 가져온 사진은 워터마크·인물 사진을 걸러내지만, 그래도 저작권을 완전히 보장하지는
  않습니다. 상업적으로 쓰실 거라면 AI 생성 사진을 쓰시거나 사진을 직접 확인해 주세요.

이 안전장치들은 실수로 지우거나 낮추지 마세요.

## 문제가 생겼을 때

| 화면에 뜨는 말 | 뜻 | 해보실 것 |
|---|---|---|
| AI를 실행하는 프로그램을 찾을 수 없음 | `claude` 가 안 깔려 있음 | 1번 항목의 설치 과정을 다시 확인해 주세요 |
| 오늘 AI 사용량을 다 씀 | Claude 구독 한도 도달 | 안내된 시간(보통 저녁) 이후 다시 시도해 주세요 |
| 네이버 로그인이 풀림 | 세션 만료 | **[네이버 로그인]** 을 다시 누르고, 이번엔 "로그인 상태 유지"를 꼭 체크해 주세요 |
| 이미 켜져 있다는 메시지(4123) | 앱이 이미 실행 중 | 브라우저에서 http://localhost:4123 을 그냥 열어보세요 |
| Cloudflare 키 없음 | AI 사진 생성 기능만 못 씀 | 사진 소스를 "검색해서 가져오기"로 바꾸면 바로 쓸 수 있습니다 |

이 표에 없는 문제라면, 화면에 나온 메시지를 그대로 캡처해서 개발자에게 보여주세요.

## 참고: 어떤 파일이 어디에 저장되나요

- 로그인 정보, 만든 글, 사진, 발행 스크린샷: 전부 이 폴더 안 `data/` 폴더
- 이 폴더를 지우면 로그인 정보와 만든 글 기록이 전부 사라집니다(다시 만들 수는 있습니다).
